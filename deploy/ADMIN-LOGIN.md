# ورود مدیر با نام کاربری و رمز عبور

پنل مدیریت ترابوت صفحه‌ی ورود جدای خودش را دارد. بقیه‌ی کاربران با شماره موبایل و کد پیامکی وارد می‌شوند. مدیر اینجا با **نام کاربری و رمز عبور** وارد می‌شود.

> **رمز عبور را هرگز در این فایل یا هیچ فایل دیگری از مخزن ننویسید.** مخزن‌ها روی GitHub عمومی‌اند، پس هر چه در git باشد عملاً عمومی است. رمز فقط موقع اجرای دستور تایپ می‌شود و فقط هش آن (argon2) در دیتابیس می‌ماند.

---

## آدرس ورود

```
https://<دامنه‌ی پنل>/auth/admin
```

- بعد از ورود، صفحه‌ی «رسیدهای پرداخت» پنل مدیریت باز می‌شود.
- اگر کسی بدون ورود صفحه‌ای از `/admin/...` را باز کند، به همین صفحه فرستاده می‌شود.
- فقط حسابی که نقش **ADMIN** دارد با این روش وارد می‌شود. حساب‌های دیگر با رمز درست هم رد می‌شوند.
- ورود با موبایل و کد (`/auth/login`) برای مدیر هم کار می‌کند.

### محافظت

| مورد | رفتار |
|---|---|
| رمز اشتباه، نام کاربری ناشناخته، یا حساب غیرمدیر | همه یک پیام می‌گیرند: «نام کاربری یا رمز عبور درست نیست.» |
| ۵ تلاش ناموفق پشت‌سرهم | آن نام کاربری ۱۵ دقیقه قفل می‌شود، حتی با رمز درست |
| ذخیره‌ی رمز | فقط هش argon2id در ستون `User.passwordHash`. این ستون هیچ‌وقت همراه اطلاعات حساب خوانده یا برگردانده نمی‌شود. |

## تنظیم یا تغییر نام کاربری و رمز عبور

هر دو با یک دستور تنظیم می‌شوند. اجرای دوباره، مقدار قبلی را عوض می‌کند. نیازی به ری‌استارت نیست.

### روی سرور

```bash
ssh -i ~/.ssh/id_ed25519_vps deploy@79.127.99.134
cd /opt/trabot/deploy
docker compose exec -T transport npm run admin:password -- <نام‌کاربری> '<رمز عبور>'
```

مثلاً برای تغییر فقط رمز (نام کاربری همان `admin` می‌ماند):

```bash
docker compose exec -T transport npm run admin:password -- admin '<رمز تازه>'
```

### روی سیستم توسعه

```bash
cd ~/Transport/transport_backend
npm run admin:password -- <نام‌کاربری> '<رمز عبور>'
```

### نکته‌ها

- **رمز را حتماً داخل `'...'` (کوتیشن تکی) بگذارید.** نویسه‌هایی مثل `$`، `%`، `!` و `&` بدون کوتیشن را شل تفسیر می‌کند و رمز چیز دیگری ذخیره می‌شود.
- **حداقل طول رمز:** ۸ نویسه.
- **چند حساب ADMIN:** اگر بیش از یک حساب ADMIN هست، موبایل حساب مورد نظر را هم بعد از رمز بنویسید:
  ```bash
  npm run admin:password -- admin '<رمز عبور>' 09121234567
  ```
- **نام کاربری تکراری:** نام کاربری نباید مال حساب دیگری باشد. اگر باشد، دستور خطا می‌دهد و چیزی عوض نمی‌شود.
- **تاریخچه‌ی شل:** دستور رمز را در تاریخچه‌ی شل سرور نگه می‌دارد. اگر نمی‌خواهید بماند، یک فاصله پیش از دستور بگذارید (وقتی `HISTCONTROL=ignorespace` باشد) یا بعدش `history -d` بزنید.
- **پیام موفقیت:** دستور در پایان فقط می‌نویسد کدام حساب (با موبایلش) تنظیم شد؛ رمز را نشان نمی‌دهد.

### پیش‌نیاز (یک بار)

ستون `passwordHash` با migration `1790770000000-UserPasswordHash` ساخته می‌شود. `ship.sh` migrationها را خودکار اجرا می‌کند. اگر دستی لازم شد:

```bash
docker compose exec -T transport npm run typeorm -- migration:run
```

---

## اگر رمز فراموش شد

همان دستور بالا را با رمز تازه روی سرور اجرا کنید. رمز قبلی قابل بازیابی نیست، چون فقط هش آن ذخیره شده است.

## اگر نام کاربری قفل شد

بعد از ۱۵ دقیقه خودش باز می‌شود. برای باز کردن فوری:

```bash
docker compose exec -T redis redis-cli DEL "auth:admin-signin-failures:v1:<نام‌کاربری با حروف کوچک>"
```
