# راه‌اندازی ربات بله

ربات بله یک **ربات رسمی** است با APIای شبیه تلگرام، و نصب یا دانلود جداگانه ندارد. فقط توکن لازم است.
کد مربوط: `src/services/messengerBot/bale/baleBot.service.ts`. منطق ربات با تلگرام مشترک است.

> **هشدار:** توکن ربات را هیچ‌جا نفرستید.
> برای سیستم محلی و سرور **دو ربات جدا** بسازید (بخش «محلی و production»).

---

## ۱. ساخت ربات

1. در بله به `@botfather` پیام بدهید و ربات تازه بسازید.
2. اسم نمایشی (مثلاً «ترابوت») و یک آیدی که به `bot` ختم شود بدهید (مثلاً `tarabot_bot`).
3. توکن ربات را بگیرید.

عکس و توضیح ربات را هم از همان‌جا تنظیم کنید.

## ۲. متغیرهای `.env` بک‌اند

```env
BALE_BOT_TOKEN=<توکن botfather بله>
BALE_BOT_USERNAME=tarabot_bot
# اختیاری؛ پیش‌فرض همین است
# BALE_BOT_API_URL=https://tapi.bale.ai
```

| متغیر | توضیح |
| --- | --- |
| `BALE_BOT_TOKEN` | توکن ربات؛ خالی یعنی ربات بله خاموش |
| `BALE_BOT_USERNAME` | آیدی ربات بدون `@`؛ برای لینک‌های دعوت (`https://ble.ir/<آیدی>?start=<کد>`). خالی یعنی لینک بله در دعوت‌ها نمی‌آید. |
| `BALE_BOT_API_URL` | اختیاری؛ آدرس API بله |

ربات بله همیشه با **polling** کار می‌کند. webhook، دامنه یا HTTPS لازم ندارد.

## ۳. ری‌استارت بک‌اند

| پیام لاگ | معنی |
| --- | --- |
| `BALE_BOT_TOKEN is not configured. Bale bot is disabled.` | توکن خالی است |
| `Bale bot started in polling mode.` | ربات روشن شد |
| `Failed to start Bale bot: ...` | توکن اشتباه است یا سرور به `tapi.bale.ai` نمی‌رسد |

## ۴. تست

1. در بله ربات را باز کنید و شروع را بزنید.
2. دکمه‌ی «ارسال شماره» را بزنید.
3. اگر این شماره در ترابوت ثبت‌نام کرده باشد، حساب وصل می‌شود و منو می‌آید.

## محلی و production

- **دو ربات جدا بسازید**. دو برنامه‌ای که با یک توکن polling کنند، آپدیت‌ها را از دست هم می‌گیرند و پیام‌ها گم می‌شوند.
- فقط **یک نسخه** از بک‌اند را با هر توکن اجرا کنید.
