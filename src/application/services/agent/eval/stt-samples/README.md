نمونه‌های `npm run agent:eval-stt`: هر فایل صوتی (ogg، webm، wav، m4a، mp3) کنار یک فایل
هم‌نام `.txt` که متن دقیقِ گفته‌شده در آن است. مثلاً `cargo-01.ogg` و `cargo-01.txt`.
بهتر است ویس واقعی از پیام‌رسان‌ها و میکروفون وب باشد، با لهجه‌ها و نویزهای مختلف.

برای مقایسهٔ VAD روشن و خاموش با راهنمای فعلی:

```bash
npm run agent:eval-stt -- --vad both
```

مدل Silero در `uploads/stt-models/ggml-silero-v6.2.0.bin` قرار می‌گیرد. این پوشه
در Git نیست؛ برای استقرار روی سرور جدید، مدل را جداگانه دانلود کنید:

```bash
mkdir -p uploads/stt-models
curl -L --fail https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v6.2.0.bin -o uploads/stt-models/ggml-silero-v6.2.0.bin
```

در صورت موجود بودن مدل، VAD پیش‌فرض فعال است. `WHISPER_VAD=off` آن را خاموش می‌کند.
برای مدل در مسیر دیگری `WHISPER_VAD_MODEL` را به مسیر کامل فایل تنظیم کنید.
تست با `--vad on` اگر مدل موجود نباشد خطا می‌دهد تا نتیجهٔ بدون VAD به نام VAD گزارش نشود.

CER تفاوت نوشتن عدد به حروف و رقم را هم خطا حساب می‌کند؛ کد بار، پلاک، مبلغ،
اسم شهر و نفی دستورها را جدا بررسی کنید. برای ارزیابی مستقل، نمونه‌های جدید
با شهرها و گوینده‌هایی که در تنظیم راهنما استفاده نشده‌اند اضافه کنید.
